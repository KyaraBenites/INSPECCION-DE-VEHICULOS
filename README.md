# Inspección de flota liviana SDE

1. Extraer el ZIP. Subir index.html, style.css, app.js y la carpeta assets al directorio raíz de un repositorio GitHub. No subir inspecciones completadas, firmas, huellas o fotos personales.
2. En Settings → Pages → Build and deployment, elegir Deploy from a branch, main, /(root), Save.
3. Abrir el enlace que GitHub Pages muestra, en HTTPS. No requiere servidor ni dependencias externas.

Los textos del formulario se editan tocándolos. Estado: B, M, NA, CH; la X en el vehículo es independiente. Se puede tomar una foto o elegir una imagen para cada evidencia, firma y huella. Para huella, fotografiar una impresión real en papel blanco con buena luz: no se puede leer el sensor del teléfono. La firma dibujada o importada se guarda como PNG. Las firmas son gráficas, no firmas criptográficas certificadas.

Guardar conserva el borrador en IndexedDB del mismo navegador y origen. Copia editable descarga JSON con todos los datos; Abrir copia lo restaura en otro dispositivo. No hay sincronización ni almacenamiento en GitHub. Mantener las copias en un lugar protegido; contienen datos personales. Borrar los datos del navegador elimina el borrador local. PDF y Word preservan el diseño como imágenes; Word no tiene campos editables. PNG genera un ZIP de imágenes si hay anexos. La disponibilidad del enlace depende de GitHub y la cuenta.
